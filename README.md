# Controle de Disponibilidade - Baterias, Paletes e Painéis

Sistema web responsivo para mapeamento e controle de bloqueios de painéis em baterias industriais. Desenvolvido para uso rápido em computadores e celulares via navegador.

## Recursos
- Mapeamento visual interativo dos painéis por palete e quadrante.
- Atualização em tempo real de estatísticas de disponibilidade e indisponibilidade.
- Exportação de dados consolidados em formato CSV.
- Armazenamento local automático (`LocalStorage`).

## Como acessar
O aplicativo pode ser hospedado de forma gratuita diretamente no **GitHub Pages** através da aba *Settings > Pages* deste repositório.
